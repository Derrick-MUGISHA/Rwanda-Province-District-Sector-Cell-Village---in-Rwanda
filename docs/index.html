    why trust it

    Built to be audited

    Official source, cited

    Generated from the NISR "List of Villages" publication; the snapshot date ships inside the data as dataVersion.

    No silent data loss

    The build fails if a single village code in the source document is missing from the output.

    Standard codes

    NISR codes at every level plus ISO 3166-2 codes for provinces, so the data joins cleanly with any international system.

    Stable ids, with migrations

    When an id changes between releases, changes.json maps old to new and resolveId() follows it.

    Community-corrected

    Spotted a wrong village? Open a data-correction issue — reports from people who know these places keep the data honest.

    Electrification context

    Each village carries its National Electrification Plan category (grid, solar, or microgrid) from the source document.
